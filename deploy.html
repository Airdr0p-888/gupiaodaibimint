Deploy Guide

一键部署指南

浏览器内编译 + 部署，无需本地环境。连接钱包后即可完成「发射台 → 主代币 → 交易对 → 开启 Mint」全流程，全程链上确认。

1

连接钱包

连接 MetaMask / TokenPocket，自动检测 BSC 主网；页面会自动填入 Pancake V2 Router、WBNB / USDT 等默认地址。

2

浏览器内编译

solc 0.8.26 在浏览器内直接编译 DBurnMintLaunchpad.sol + BurnToken.sol，编译完成后输出 ABI（Launchpad 87 项 / BurnToken 69 项）。

3

部署 Launchpad 发射台

钱包确认部署发射台合约，得到 Launchpad 地址。当前连接钱包自动作为 launchOperator / taxProcessor / stairTaxReceiver 默认值。

4

写入 Launch 配置

写入代币名称、符号、总供应量、Mint 价格与份数、白名单、税率、流动性分配、交易开放时间等全部启动参数。

5

部署 BurnToken 主代币

Clone 部署主代币合约，按 tradingOpenTime 时间自动开盘（非手动 openTrading()）。

6

创建 / 读取 Pair

Pair 地址可留空，部署后自动创建 Pancake V2 交易对，或读取已存在的 Pair 地址。

7

初始化 Token

初始化主代币合约，绑定发射台与交易对，完成代币启动前的最后配置。

8

开启 Mint

开启 Mint 通道，用户即可用 BNB 或指定股票代币参与 Mint。满额自动结束，或后台手动关闭。

Version Notes

当前版本重要前提

1BurnToken 按 tradingOpenTime 时间自动开盘，不是 openTrading() 式手动开盘。
2后台页的「开启交易」逻辑，在本版本体现为「同步交易状态」。
3Pair 地址可以留空，部署后会自动尝试创建或读取。
4LP 分红不在这个版本里。
5Mint 没有结束时间，满额自动结束，或者后台手动关闭。
